# قبله‌نما و اوقات شرعی — پروژه اندروید (Kotlin / Jetpack Compose)

**طراح و توسعه‌دهنده:** امید شاهین مهر — Omidshahinmehr@gmail.com

## نحوه بازکردن پروژه
1. Android Studio (نسخه Koala یا جدیدتر) را باز کنید.
2. گزینه‌ی **Open** را انتخاب کرده و پوشه‌ی `QiblaApp` را انتخاب کنید.
3. صبر کنید تا Android Studio به‌طور خودکار Gradle Wrapper را بسازد و پروژه Sync شود.
4. با دکمه Run ▶ برنامه را روی شبیه‌ساز یا گوشی اجرا کنید.

## ویژگی‌ها
- **سه زبانه (فارسی/انگلیسی/عربی)**: رابط کاربری، اعلان‌ها و ویجت به‌طور خودکار بر اساس زبان سیستم گوشی نمایش داده می‌شوند (راست‌به‌چپ برای فارسی/عربی، چپ‌به‌راست برای انگلیسی)، و نام ۸۰+ شهر پیش‌فرض هم در هر سه زبان ترجمه شده.
- محاسبه‌ی جهت قبله و فاصله تا کعبه به‌صورت محلی (بدون نیاز به سرویس خارجی).
- دریافت اوقات شرعی از سرویس Aladhan با `method=7` (مؤسسه ژئوفیزیک دانشگاه تهران).
- فهرست گسترده‌ی شهرهای پیش‌فرض (بیش از ۸۰ شهر): حرمین شریفین، شهرهای زیارتی عراق، استان‌های ایران، و شهرهای مهم جهان + افزودن شهر دلخواه از نقشه، جست‌وجو، یا موقعیت فعلی.
- **زنگ اذان**: برای هر اذان می‌توان یادآوری روشن کرد و صدای دلخواه (از فایل‌های گوشی یا زنگ‌های سیستمی) انتخاب کرد.
- **یادآوری قبل از اذان**: اعلان سبک چند دقیقه پیش از هر اذان (قابل تنظیم: ۵ تا ۳۰ دقیقه)، جدا از خود آلارم.
- **جدول اوقات شرعی ماهانه**: مرور کل اوقات شرعی یک ماه با امکان جابه‌جایی بین ماه‌ها.
- **جست‌وجوی شهر با نام**: جست‌وجوی آنی در فهرست شهرهای موجود + جست‌وجوی آنلاین جهانی (در صورت اتصال اینترنت).
- **قبله‌نمای زنده**: با سنسور قطب‌نمای گوشی، عقربه هم‌زمان با چرخاندن گوشی حرکت می‌کند (در نبود سنسور، به‌صورت ثابت رو به شمال نمایش داده می‌شود).
- **حالت روشن/تیره**: دکمه‌ی تعویض ظاهر در بالای صفحه‌ی اصلی؛ انتخاب کاربر ذخیره و در اجراهای بعدی حفظ می‌شود.
- **ویجت صفحه‌ی اصلی**: نمایش اوقات شرعی امروز به همراه تاریخ شمسی و قمری، حتی بدون باز کردن اپ.
- صفحه‌ی «درباره» با نام طراح و راه ارتباطی.
- پشتیبانی از **Android 5.0 (API 21)** به بالا و صفحه‌نمایش‌های کوچک/قدیمی.
- ذخیره‌سازی شهرها، تنظیمات آلارم و آخرین اوقات دریافتی با SharedPreferences (بین اجراهای برنامه باقی می‌ماند).

## نیازمندی‌ها
- اتصال اینترنت برای دریافت اوقات شرعی و تصویر نقشه.
- مجوز موقعیت مکانی برای دکمه‌ی «موقعیت فعلی من».
- مجوز نوتیفیکیشن (اندروید ۱۳+) برای نمایش هشدار اذان.
- برای دقیق‌ترین زمان‌بندی آلارم در اندروید ۱۲+، فعال‌کردن مجوز «زمان‌بندی دقیق» از داخل برنامه (بنر راهنما در صفحه‌ی زنگ اذان نمایش داده می‌شود).

## افزودن صدای اذان
به دلایل حجم برنامه و حق نشر، فایل صوتی اذان از پیش در برنامه قرار داده نشده است. از صفحه‌ی «زنگ اذان» می‌توانید صدای دلخواه (از حافظه‌ی گوشی یا زنگ‌های سیستمی) را برای هر اذان جداگانه انتخاب کنید.
